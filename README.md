# React Chat Application

A modern real-time chat application built with React and Firebase.

## Features

- 💬 Real-time messaging
- 🔐 User authentication (Google/Email)
- 📱 Responsive design
- 😊 Emoji support
- ⏱ Message timestamps
- 💡 Dark/Light mode
- ✔️ Online status indicators

## Tech Stack

- React.js
- Firebase (Auth, Firestore)
- React Router
- Material-UI/TailwindCSS
- React Icons
